# جوامع الکلم — ڈاکٹر عمران حیات کی تدریسی پیشکش

اردو میں احادیث کے مطالعے کے لیے ایک رنگین، سادہ اور مکمل طور پر جامد ویب سائٹ۔ HTML، CSS اور JavaScript پر مبنی ہے؛ کسی اکاؤنٹ، سرور، ڈیٹابیس یا بلڈ مرحلے کی ضرورت نہیں۔

## شامل مواد

- مفتی محمد شفیعؒ کی چہل حدیث کی ترتیب میں 40 مکمل اسباق۔
- اعراب والا عربی متن، آسان اردو مفہوم اور بنیادی کتاب کے مطابق مختصر حدیثی حوالہ۔
- نئی تدریسی تشریح، روزمرہ مثال اور ہر سبق کے لیے عملی سرگرمی۔
- 309 لفظی اندراجات: عربی لفظ، اردو معنی، انگریزی معنی اور ابتدائی نحوی تجزیہ۔ یہ منفرد الفاظ کی گنتی نہیں؛ تکرار والے الفاظ بھی شامل ہیں۔
- ہر حدیث کے لیے 8 مختصر سوالات و جوابات کا الگ ٹیب، 3 وضاحتی MCQs اور خالی جگہ مکمل کرنے کی مشق۔ مجموعی طور پر 120 MCQs۔
- دوسری فراہم کردہ کتاب کے 30 مرکزی ابواب سے موضوعاتی مطالعات: وضاحت، مثال، غور و فکر اور متعلقہ بنیادی حدیث کا ربط۔ یہ پوری دوسری کتاب کے ہر ضمنی مبحث کی مکمل باز تحریر نہیں۔
- تلاش، موضوعاتی چھانٹی، محفوظ اسباق، ذاتی نوٹس، تکمیل کی پیش رفت، فلیش کارڈز اور پیش رفت کی نقل محفوظ/بحال کرنے کی سہولت۔
- 10، 20، 50، 100 یا تمام دستیاب سوالات کا مجموعی جائزہ؛ اختیارات اور سوالات کی ترتیب بدلتی ہے۔
- ہر حدیث اور اضافی مطالعے کا الگ مستقل رنگ: مجموعی طور پر 70 رنگوں کے مجموعے، دن/رات میں واضح متن۔
- مجموعی طور پر 440 مختصر سوالات و جوابات: چالیس اسباق میں 320 اور تیس اضافی مطالعات میں 120۔ جوابات الگ الگ یا ایک ساتھ کھولنے اور چھپانے کی سہولت۔
- ہر حدیث میں تعلیمی مقاصد، ابتدائی سوال، مرکزی سبق، اہم وضاحت، عملی مثال، خود جانچ اور وقفے کے ساتھ دہرائی۔
- واضح دن/رات تھیم، موبائل فہرست، مقامی امیری اور جمیل نوری نستعلیق فونٹس۔
- صارف کی ہدایت کے مطابق کوئی PDF، سکین صفحہ یا کتاب کا عکس شامل نہیں۔ تمام مطالعہ ویب صفحات کے اندر ہے۔

## فوراً کھولنے کا طریقہ

فولڈر سے `index.html` کھولیں۔ زیادہ مستقل براؤزر رویے اور پیش رفت کے لیے مقامی سرور یا GitHub Pages استعمال کریں۔ مثال:

```sh
python3 -m http.server 8000
```

پھر براؤزر میں `http://localhost:8000` کھولیں۔ کوئی npm انسٹالیشن ضروری نہیں۔

## GitHub Pages پر لگانے کا طریقہ

1. نیا GitHub repository بنائیں، مثلاً `jawami-learning`۔
2. اس فولڈر **کے اندر کی فائلیں** repository کی جڑ میں رکھیں، تاکہ `index.html` اوپر کی سطح پر ہو۔ `.github` کا پوشیدہ فولڈر بھی شامل رکھیں۔
3. فائلیں `main` branch پر push کریں۔
4. Repository میں **Settings → Pages → Build and deployment → Source → GitHub Actions** منتخب کریں۔
5. **Actions** میں موجود **Deploy learning website to GitHub Pages** workflow چلائیں؛ اگلی `main` push پر یہ خود بھی چلے گا۔
6. کامیابی کے بعد Pages میں دیا گیا ویب پتہ استعمال کریں۔

سادہ متبادل: Source میں **Deploy from a branch**، پھر `main` اور `/(root)` منتخب کریں۔ دونوں طریقوں میں سے ایک منتخب کریں۔ تمام اثاثوں کے روابط relative ہیں، اس لیے project repository کے ذیلی راستے پر بھی کام کرتے ہیں۔

GitHub کی سرکاری رہنمائی: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## فائلوں کی ترتیب

| فائل | کام |
|---|---|
| `index.html` | بنیادی صفحہ، عنوان اور مرکزی نیویگیشن |
| `style.css` | رنگ، فونٹس، موبائل ترتیب اور دن/رات تھیم |
| `app.js` | اسباق، تلاش، جائزہ، دہرائی اور محفوظ پیش رفت |
| `data.js` | چالیس احادیث کا تدریسی مواد |
| `palette.js` | اسباق اور اضافی مطالعات کے 70 مستقل رنگ |
| `supplement.js` | دوسری کتاب کے تیس موضوعاتی مطالعات |
| `assets/fonts/` | مقامی فونٹس اور ان کے نوٹس |
| `assets/icon.svg` | ویب سائٹ کا نشان |
| `scripts/validate.cjs` | مواد، اختیارات اور ضروری فائلوں کی جانچ |
| `.github/workflows/pages.yml` | GitHub Pages deployment |

## مواد میں تبدیلی

`data.js` میں ہر حدیث کا الگ اندراج ہے۔ عربی متن، الفاظ کے اندراجات سے مل کر بنتا ہے؛ کسی لفظ کو بدلتے وقت متعلقہ معنی، نحو اور MCQ بھی دیکھیں۔ IDs مستقل رکھیں تاکہ محفوظ نوٹس اور پیش رفت درست رہیں۔ `supplement.js` میں اضافی مطالعات اور مطبوعہ صفحات کے حوالے ہیں۔

```sh
node --check app.js
node --check data.js
node --check supplement.js
node scripts/validate.cjs
```

## مآخذ اور علمی دائرہ

اصل فراہم کردہ کتابیں `SOURCES.md` میں درج ہیں۔ حدیث کے بعد درج صفحہ بنیادی چہل حدیث کا مطبوعہ صفحہ ہے۔ اضافی مطالعے میں صفحات دوسری کتاب کے ہیں۔ روایات کی مختصر نسبتیں بنیادی نسخے کے مطابق ہیں؛ تمام روایات کی مستقل تخریج یا فقہی تحقیق کا دعویٰ نہیں۔ تشریح، مثالیں، سوالات اور سرگرمیاں اس پیشکش کے لیے نئے تدریسی انداز میں مرتب ہیں۔

## پیش رفت اور رازداری

نوٹس، مکمل اسباق، محفوظ اسباق اور جائزے صرف اسی براؤزر کے localStorage میں رہتے ہیں۔ کوئی analytics، اکاؤنٹ، خارجی API یا خودکار اپلوڈ نہیں ہے۔ مختلف آلے یا براؤزر پر نقل لے جانے کے لیے **دہرائی → پیش رفت کی نقل محفوظ کریں** استعمال کریں۔ براؤزر ڈیٹا صاف ہونے یا private browsing ختم ہونے سے مقامی پیش رفت مٹ سکتی ہے۔
